## 座標変換そのもの

今回の床・壁から作った固定済み変換を使い、SDKの元関節から独立に再計算した。

|照合|最大差|
|---|---:|
|ランナーの `bodies_corridor.csv` と独立再計算|0 m|
|ZED→廊下の直接変換と、ZED→LiDAR→水平化→廊下の合成|8.9×10⁻¹⁵ m|
|変換後から元座標へ戻した値と元SDK関節|3.6×10⁻¹⁵ m|
|剛体変換による骨の長さの変化|7.3×10⁻¹⁶ m未満|

回転行列の行列式は約+1、直交性も浮動小数点の丸め範囲で満たす。単位の1000倍違い、軸・符号の取り違え、水平化の二重適用を示す不整合は見つからない。これは計算の整合性であり、入力関節や校正の真の正確さを証明する値ではない。

SDKの3D関節を内部パラメータで画像へ再投影すると、SDK自身の2D関節との画素差は最大約0.000067 px。ただし、同じSDK由来の2D/3Dの整合性であり、実際の人体へ正しく重なっていることの独立検証には使わない。画像も確認し、人物との対応はあるが、遠方の足の位置・姿勢は安定した実測と判定しない。

## 廊下内の位置とLiDARとの比較

- ZED骨盤の廊下方向Xは **0.314〜14.807 m**、横位置Yは **−0.160〜+0.209 m**。初期推定は13.99 m付近から一時増加し、その後は手前へ移る。初期化直後の位置も安定した正解とは扱わない。
- LiDARの選定実観測85点それぞれに、60 ms以内の最も近いSDK骨盤1点だけを対応させた。30 Hz SDKを10 Hz LiDARへ重複対応して観測数を増やしていない。
- **確定LiDAR実検出33組**では、骨盤とLiDAR代表点の差の絶対値中央値は、X **0.066 m**、Y **0.017 m**。90百分位はX **0.096 m**、Y **0.045 m**。
- **未確定候補も含む85組**では、差の絶対値中央値はX **0.088 m**、Y **0.036 m**、90百分位はX **0.372 m**、Y **0.104 m**。Xの最大差は約0.96 m。15 m付近のLiDARは未確定であり、確定33組は近距離だけの比較。

これらはセンサー間の異なる代表点の差であり、身体中心の測位誤差ではない。今回も時計offsetは推定・適用しておらず、廊下方向のセンサー原点差は暫定0 m。近傍ヘッダー時刻が約1 msで一致していても、動体の同期精度は証明できない。廊下端からの15 m原点、絶対位置の精度を保証する数値には使わない。

## 骨格の高さ・脚長で残る問題

1. **遠方で床下に入る足がある。** 7.2〜10秒付近のかかとは、今回の推定床面に対して中央値約−0.159 m、最小 **−0.278 m**。confidence 25以上で画像内にあるかかとでもこの値が出る。少なくとも片方が−0.10 mを下回る、同条件のフレームは57件。これは推定床面との関係であり、真値に対する28 cmの測位誤差と確定したわけではない。
2. **脚の長さが距離によって変わる。** 同じ人物の17〜19秒を比較用に固定すると、大腿の中央値は約0.377 m、下腿約0.335 m。遠方・初期には大腿最大約0.569 m、下腿約0.506 mで、近距離基準の **約1.51倍**になる。これらの変動は元のIMAGE座標に既に存在する。廊下座標への剛体変換は骨長を変えないため、変換計算によって生じた伸縮ではない。身体寸法の実測値はなく、17〜19秒の値も真値ではない。
3. **近距離の終端では足が画角外へ出る。** 19秒以降は両脚のconfidenceが下がり、SDK状態OKでも画像外の関節を推定している。表示される骨格を全て観測できた関節として数えない。
4. **ZEDの床面校正自体にも変動がある。** 前段の未使用12〜14秒で床を再推定した結果は、15 m先で約−0.101 mの高さ差に相当した。足の床下位置をSDKだけ、または座標校正だけが原因と断定できない。脚長変動は剛体変換では説明できないため、少なくともSDK推定側にも確認事項が残る。

`HEAD` 関節高も全体で約1.39〜1.67 mと変化するが、頭頂高の測量値ではなく、姿勢やSDK推定も含む。身長の真値・誤差として扱わない。

今回の再生では、形状チェックの参照を **同じ録画の17〜19秒**として明示した。以前の録画の被験者や、テンプレートの暗黙の4.5〜10.5秒基準は使っていない。形状フラグは参照骨長の0.5〜1.8倍という粗い目印のため、1.5倍の伸縮が通過しても正常という判定ではない。原関節の補正・床への吸着・スケール調整は行っていない。

## 現時点の判断

**廊下中央を近づく大まかな経路の確認には使える。15 m付近からの関節の高さ、脚長、歩幅・関節角などの定量測定を承認できる状態ではない。**

次の改善確認では、今回の設置で測量した共通ターゲット等により廊下方向の原点・並進を拘束し、未使用の床面・位置で校正を確認する。関節の定量評価には実測身体寸法や独立した関節位置の基準が必要。人物の足が全区間で画角内にあることも確認する。見た目を合わせるために既存JSONや骨格座標を直接調整しない。
