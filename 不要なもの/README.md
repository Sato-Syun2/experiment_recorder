# 不要なもの（2026-10-22整理）

今回使う録画・解析・再生と、その前提となる計画作成・校正の現行プログラムは、リポジトリ直下の `scripts/` に残した。通常の実験実行に使わない旧版・過去の解析レポート・開発用ファイル・参考資料を、このフォルダーへ移動した。削除はしていない。作業前からの未コミット変更も内容を変えずに移動している。

## 移動したもの

| 元の場所 → このフォルダー内の場所 | 理由 |
| --- | --- |
| `reports/` → `reports/` | 過去の解析レポート、画像・HTML・出力、録画別の検証コード、変更前コード。関連ファイルをフォルダーごと保持。 |
| `tracking/20261013_group001_recording_001_analysis.md` → 同じ相対パス | 過去録画の単独解析レポート。 |
| `scripts/run_recording003_approach_only_20261022.py` → 同じ相対パス | 過去の録画003・接近区間の準備済みパッケージ専用ランチャー。 |
| `scripts/run_recording003_skeleton_replay_20261021.py`、`.ps1` → 同じ相対パス | 過去の録画003の準備済みパッケージ専用ランチャー。 |
| `scripts/benchmark_tracking.py` → 同じ相対パス | 旧版との比較に使った開発用の合成データベンチマーク。 |
| `tests/` → `tests/` | 開発用の回帰・品質確認テスト。 |
| `calibration_gui/` → `calibration_gui/` | 現行プログラムと独立した手動校正GUI、デモ、付属テスト。設置校正用の現行CLIは `../scripts/` に保持。 |
| `Livox_Mid-360s_User_Manual_en.pdf` → 同名 | 機器参考資料。 |
| `ZED 2i - Datasheet - V1.5 - 2026-09-22.pdf` → 同名 | 機器参考資料。 |

移動は10項目、合計966ファイル（付属画像・キャッシュ等を含む）。ファイルごとの元パス、移動先、移動理由、サイズ、SHA-256は [移動一覧.json](移動一覧.json) に記録した。

骨格再生ビルダー・骨格確認・接近比較とテンプレートの現行版は `../scripts/` に保持している。`reports/` に含まれる古い版や検証当時のコピーは履歴として退避した。日付付きランチャーは共有先の準備済みファイル名・フォルダー構造を前提としており、現行の汎用プログラムの入口ではない。

## 保持したデータと環境

- 録画原本、録画付属資料、既存メタデータ、ログ、`config.json`、`run_order.json`、元Excel、校正JSONを変更していない。
- `tracking/` のCSV・比較HTML・画像・解析メタデータは、現行プログラムの既定入力や過去解析の入力として参照されるため元の場所に保持した。
- `.git/`、`.venv/`、`.vscode/` などの管理・実行環境は保持した。
- 共有先 `/data/experiment_data/` は変更していない。
- 新規レポートの出力用に、ルートの `reports/` は空の出力フォルダー（`.gitkeep` のみ）として用意した。

## 再参照と復元

過去レポートの入口は [reports/INDEX.md](reports/INDEX.md)。退避内の文書・プログラムに書かれたパスやコマンドは検証当時のものを保持している。絶対パスやリポジトリ直下を前提とした相対パスは、移動先に合わせた読み替えが必要。

復元する場合は `移動一覧.json` の `source` に記録された元の相対パスへ戻す。復元先にファイルがある場合は上書きせず内容を比較する。`reports/` 全体は新規の解析結果と混ぜず、必要な過去案件だけ戻す。`tests/` は元のルート `tests/` に戻してから使用する。退避プログラムをこのフォルダーから直接実行すると、設定やimportの相対パスが合わない場合がある。

この整理ではテストやプログラム実行、実機操作を行っていない。
