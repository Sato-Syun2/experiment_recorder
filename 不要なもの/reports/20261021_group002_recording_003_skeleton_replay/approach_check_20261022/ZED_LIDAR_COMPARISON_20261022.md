# 録画003：接近区間のZED SDK / LiDAR比較

対象は2026-10-21 group002 recording003の17.00〜26.50秒、画面奥から手前へ近づく場面だけ。往路と折返しは含めない。共有出力の [比較ページ](/data/experiment_data/20261021_group002_recording_003_skeleton_replay/approach_check_20261022/runs/20261022_004410_772845/zed_lidar_comparison_20261022/index.html) から、「ZED SDKのみ」と「ZED SDK + LiDAR経路」を同じ時刻で切り替えられる。再生画面は上面図から開き、映像には同じSDK骨格を重ねる。

## 比較結果

|項目|結果|
|---|---:|
|ZED処理|285/285フレーム|
|ZED骨格出力|282/285フレーム（98.9%）|

|近い時刻のZED/LiDAR比較|245 SDKフレーム（最大時刻差65 ms以内、補間なし）|
|ZED骨盤とLiDARクラスタ中心の水平距離差|中央値16.5 cm、90百分位1.00 m|
|奥行き位置の相関|r = 0.991|

距離帯ごとの水平距離差は、LiDAR奥行き12 m以上で中央値0.99 m、8〜12 mで0.37 m、4〜8 mで8.3 cm、4 m未満で5.7 cmだった。12 m以上と8〜12 mの対応は全て未確定候補。近距離では確定検出の割合が上がる。

例えば19.00秒では、ZED骨盤の廊下奥行きが11.04 m、近い時刻のLiDAR ID 60候補が12.50 mで、約1.46 m離れて見える。20秒前後の比較画像は共有フォルダーの `browser_check/zed_plus_lidar_t19.png` と `zed_only_t19.png`。

この録画では、2つの方式は「奥から手前へ進む」全体傾向を同じように示した一方、遠距離の現在位置は目立ってずれる。よって、**大まかな進行経路を見る比較には使えるが、遠距離のLiDAR位置や数値を確定測定として使えるとは判定できない**。接近に伴って両者が近づく結果も、この録画内の比較に限る。

## 距離差の解釈

この水平距離差は絶対測位誤差ではない。ZED側の身体中心は骨盤関節、LiDAR側は可視点群クラスタの位置で、同じ物理点を測っていない。独立測量真値もない。また、奥行きが12 mを超える区間はLiDAR ID 60が未確定候補のまま。時刻は元のセンサー絶対タイムスタンプから録画画像の原点に対する相対時刻へ変換し、各SDKフレームで近い実観測を照合したが、専用の時計offset試験や同期精度の保証は行っていない。

上面図は2つの位置列を同じ廊下座標で見るため、ZED骨格を描く側にも部分的なZED-LiDAR外部変換候補を使っている。「ZED SDKのみ」はLiDARの観測点と経路を隠す表示モードで、座標変換までLiDARと独立した解析を意味しない。LiDAR点でZED骨格を補正・吸着する融合処理はしていない。
