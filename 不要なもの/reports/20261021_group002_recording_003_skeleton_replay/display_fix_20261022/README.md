# 骨格の立体表示を見やすくした再生画面

[修正版を開く](index.html)。SDKの再実行は不要。

3D表示を人物に近づけ、関節・骨の線を太くした。頭・骨盤の実際の高さZと、床Z=0 mからの高さ目盛りを表示する。表示欄の幅も修正し、データの保存先が長くても骨格の欄が縮まないようにした。床面の経路図は「床面上の経路を開く」にまとめた。

カメラは表示中の関節の範囲と床を収める。関節の元のXYZ、廊下への変換、校正候補、尺度は変更していない。床へ関節を移したり、立位へ姿勢を作り直したりする補正は行っていない。

初期表示は10秒付近の骨格。再生、時刻移動、横から・手前から・上から、ドラッグでの回転が使える。「廊下全体」で位置関係を確認し、「人物を追う」で骨格を拡大する。真上の視点では高さが見えにくいため、姿勢を見る場合は「斜め上」か「横から」を選ぶ。

形状が崩れている復路も、初期状態で元データを紫で表示する。「形状不整合の元データも表示」を外すと非表示に戻せる。約15.87秒以降の脚・胴体の崩れはSDK出力に含まれるため、この表示変更でも正しい歩行姿勢にはならない。信頼度が低い関節は従来通り既定で隠し、「低信頼度の関節」で確認できる。観測がない時刻の骨格は補わない。

元データの件数・不整合区間・精度の限界は [骨格の検証結果](../verified_20261022/README.md)。骨格CSV、SDK確認画像、既存の再生HTML・メタデータは保持し、新規の専用フォルダーに保存した。

保存済みデータだけを使い、実機やROSノードは起動していない。ユニットテストは実行していない。ブラウザーで骨格の立ち上がり、上面・側面・全体視点、再生、表示切替を確認し、JavaScript例外はなかった。幅1550 pxのブラウザーでは、10秒付近の骨格は画面上で約333 pxの高さで表示された。頭Z=1.45 m、骨盤Z=0.79 m、元の関節のZ範囲約0.02〜1.53 mを維持しており、床への投影でZを消していない。

`browser_review.json` に表示確認結果、`preview_outgoing.png` に往路、`preview_return_default.png` に復路の元データ表示を保存。`display_manifest.json` には既存版と今回の関節データ・変換値が同一であることを記録する。
