# 2026-10-13 録画のドア凹部によるZED–LiDAR校正試行

## 結果

既存録画でドア近傍の静的点群を使ったICP校正を試しましたが、**採用できる校正値にはなりませんでした**。候補JSONは診断用に保存しましたが、`tracking/lidar_to_zed_left_eye.json` へは適用していません。

対象は `/data/experiment_data/recording_001_svo_review` と `/data/experiment_data/recordings/20261013_group001/recording_001/lidar`（`/livox/lidar`）です。録画開始後、ZED経過時間0–8秒の空の廊下を使用しました。前半0–4秒のLiDAR 40フレーム・ZED深度8フレームで、画像内の左右手前ドア領域に限定した3D点群ICPを行いました。後半4–8秒のLiDAR 40フレーム・ZED深度8フレームは最適化に使わず、静的構造への整合を確認しました。カメラとLiDARが動かない区間なので、ここでは人物の時刻同期を校正条件にしていません。

## 何が足りないか

今回の処理ではドア角を個別に対応付けず、画像上の近距離左右領域から自動抽出した点群にICPをかけています。自動対応が不安定なので、次に進めるなら次のいずれかが必要です。

1. **手動の共通特徴点対応**: 画像・ZED深度とLiDAR点群で同じドア枠の角、凹部内側の縦枠などを少なくとも3点、できれば複数ドアにまたがる5点以上選び、画像座標・深度値・LiDAR XYZを対応付ける。似た扉の誤対応を避けるためドア番号も記録する。
2. **形状の観測性を上げる録画**: 既存設置のまま各ドア凹部へ十分近づいた点群を追加で集め、LiDARに凹部の側面・枠の縁がそれぞれ複数点入るようにする。平行な長手壁だけでは廊下方向の位置を決められないため、異なる向きの面・角を複数見せる。
3. **絶対廊下座標の基準**: 相対外部変換だけでは絶対座標は決まらない。廊下の原点となるドア枠角、長手・横手の正方向を定義し、その角から他のドア枠までを巻尺または測量器で測る。建物共通座標が必要なら建物図面または測量基準点との対応も必要。

静的形状を使う再解析のために追加のZED SDK実行は不要です。今回のレビューに既にカメラ内部パラメータ、画像、メートル単位の深度が含まれています。新しい記録を追加する場合も、同じ形式の画像・深度書き出しで足ります。既存データのドア縁がLiDAR上で十分な面密度を持つかを手動対応後に確認し、足りなければターゲット付き録画へ切り替えます。

## 技術的な背景

ターゲットレス校正自体は自然エッジや屋内構造を使う研究手法がありますが、特徴の向き・分布が推定を拘束できる必要があります。[自然エッジ分布を評価したターゲットレス校正研究](https://arxiv.org/abs/2103.01627)、[屋内壁面構造を使った校正研究](https://isprs-archives.copernicus.org/articles/XLVIII-1-W2-2023/693/2023/)も、今回のMid-360S・ZED 2i録画で必要精度を保証するものではありません。
