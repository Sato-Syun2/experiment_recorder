ZED最初の画像は `1792563507922632000 ns`。LiDARの最初・最後のヘッダー時刻は `1792563505991792672` / `1792563603091408820 ns`。絶対時刻範囲はほぼ重なり、LiDARは最初のZED画像より約1.931秒前からある。この開始差は時計ずれの推定値ではない。

- `pole_samples.jpg`: 約10、20、30、40、53、63、73秒の代表画像を原寸切り出し。
